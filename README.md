# 📻 StaroeRadio Player

Десктопный плеер для прослушивания и скачивания записей проекта **«Старое радио»** —
радиоспектаклей, литературных чтений, лекций и документальных записей из аудиоархивов:

**staroeradio.ru** · **lektorium.su** · **theatrologia.su** · **reportage.su** · **svidetel.su**

Python + tkinter/ttkbootstrap, воспроизведение через libVLC.

> 📖 Подробное руководство пользователя — в файле [USER_MANUAL.md](USER_MANUAL.md)

---

## ✨ Возможности

### Воспроизведение
- Потоковое воспроизведение MP3 по HTTP через VLC
- **Прямой эфир** трёх потоков staroeradio.ru: «Старое радио», «Музыка», «Детское радио»
  с названием текущей передачи из потока (ICY-метаданные)
- Для эфира «Старое радио» передача находится по названию в программе передач или в локальной базе —
  показываются её **обложка и описание**
- Запоминание позиции: после перезапуска воспроизведение продолжается с того же места
- Кнопка ⏮ возвращает к предыдущему **прослушанному** треку, а не к соседнему в списке
- Автопереход к следующему треку списка по окончании текущего

### Поиск
- Поиск по локальным базам всех источников сразу (все слова запроса, в любом порядке)
- **Программа передач** staroeradio.ru — загружается автоматически при первом запуске
- **История прослушивания** по дням и **избранное**
- Клик — выбор трека и его описание, двойной клик или Enter — воспроизведение

### Интерфейс
- Плеер — основная область: обложка со страницы передачи, название, статус
- Панели **Поиск**, **Лог** и **Описание** показываются и скрываются кнопками,
  размеры и видимость запоминаются
- **Мини-плеер** — только плеер в компактном окне, режим «поверх всех окон»
- Строка состояния с последним сообщением лога и счётчиком очереди скачивания
- Горячие клавиши, работающие в любой раскладке
- Тёмная тема, тёмный заголовок окна Windows, свой значок окна

### Скачивание
- Скачивание текущего трека, выбранного в списке или всех результатов поиска
- ID3-теги: название, год записи, описание передачи (Comment), обложка
- Очередь скачивания в фоне, плейлисты M3U (один трек или весь список)
- Папка сохранения задаётся в настройках один раз

### Настройки
- Окно «⚙ Настройки» с разделами: цвета и шрифты всех элементов, ползунки, кнопки, папка сохранения
- Изменения видны сразу, встроенная палитра цветов, сброс к значениям по умолчанию
- Именованные цветовые схемы

## 🚀 Установка

### 1. Python-зависимости

Нужен Python 3.9 или новее.

```bash
pip install -r requirements.txt
```

Состав `requirements.txt`:

| Пакет | Зачем |
|---|---|
| `python-vlc` | воспроизведение |
| `ttkbootstrap` | тёмная тема интерфейса |
| `Pillow` | обложки, картинки в описании, значок окна |
| `beautifulsoup4` | описания передач и программа передач |
| `mutagen` | ID3-теги при скачивании *(без него MP3 скачиваются без тегов)* |

### 2. VLC

Для воспроизведения нужны библиотеки VLC: `libvlc.dll`, `libvlccore.dll` и папка `plugins`.

- либо установите [VLC media player](https://www.videolan.org/vlc/) — разрядность должна совпадать с Python;
- либо скопируйте `libvlc.dll`, `libvlccore.dll` и `plugins/` из установленного VLC в папку со скриптом
  (обязательно для сборки в `.exe`).

### 3. Базы записей

Положите текстовые базы источников в папку `data/` (см. [ниже](#-базы-записей)).

## ▶️ Запуск

```bash
python Staroe_radio_v7.py
```

*(имя файла зависит от версии)*

При первом запуске, когда ещё нет `player_state.json`, автоматически загружается программа передач.

## 🗂 Базы записей

Локальные базы лежат в папке `data/`. Подхватываются все `*.txt` из неё.

| Файл | Источник |
|---|---|
| `data/staroeradio.txt` | staroeradio.ru |
| `data/lektorium.txt` | lektorium.su |
| `data/theatrologia.txt` | theatrologia.su |
| `data/reportage.txt` | reportage.su |
| `data/svidetel.txt` | svidetel.su |

Формат строки — `ID<TAB>Название записи`:

```
30791	Лавренёв Б. - Простая вещь - (приключения), (исп.: А.Парра, Г.Фролов, ...), (Зап.: 1987г.)
```

Результаты из `staroeradio.txt` выводятся первыми.

## 📁 Структура файлов

```
Staroe_radio/
├── Staroe_radio_v7.py        программа
├── icon.ico / icon.png       значок окна (необязательно)
├── data/
│   ├── staroeradio.txt       базы записей
│   ├── lektorium.txt
│   ├── ...
│   └── Staroe_radio.png      заглушка, когда у передачи нет обложки
├── libvlc.dll, libvlccore.dll, plugins/   VLC (если не установлен в систему)
│
│   создаются при работе:
├── player_state.json         позиция, окно, панели, папка сохранения
├── colors_config.json        цвета и шрифты
├── color_schemes/            именованные цветовые схемы
└── History/
    ├── дд.мм.гггг.txt        история прослушивания по дням
    └── favorites.txt         избранное
```

Пользовательские файлы (`player_state.json`, `colors_config.json`, `color_schemes/`, `History/`)
в репозиторий не входят (см. `.gitignore`).

**Значок окна** берётся из `icon.ico`, если его нет — из `icon.png`, если нет и его — рисуется встроенный.
Подходит .ico любого формата, в том числе с кадром 256×256.

## ⌨️ Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Пробел` | пауза / продолжить |
| `←` / `→` | перемотка на 10 секунд |
| `↑` / `↓` | громкость ±5 % |
| `Ctrl+F` | к строке поиска |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | показать/скрыть Поиск / Лог / Описание |
| `Ctrl+M` | мини-плеер |
| `Enter` | поиск (в строке поиска) / воспроизвести выбранный трек (в списке) |
| `Ctrl+C` / `Ctrl+V` | копировать / вставить — работают и в русской раскладке |

Полный список, включая действия мышью, — в [руководстве](USER_MANUAL.md#11-горячие-клавиши-и-мышь).

## 📦 Сборка в .exe (Windows)

```bash
pyinstaller Player_staroeradio.spec
```

- Перед сборкой положите `libvlc.dll`, `libvlccore.dll` и `plugins/` рядом со скриптом —
  они должны попасть в сборку.
- Папку `data/` и `icon.ico` разместите рядом с `.exe`: программа ищет их в своей папке.
- Чтобы значок был и у самого `.exe`, добавьте в сборку `--icon icon.ico`
  (или `icon='icon.ico'` в `.spec`).
