## 1. Интерфейс

```
┌─ ПОИСК ───────────────────── x ┐┌──────────────────────────────────────────────────┐
│ [ строка поиска ]   (A)  (B)   ││  ┌──────────┐   Название трека              (5)  │
│ ── 3 октября ──                ││  │ обложка  │   > Воспроизведение           (6)  │
│ 13:08  Раскин А. - ...         ││  │   (4)    │                                    │
│ 13:14  Баринов М. - ...  <-(1) ││  └──────────┘                                    │
│ 14:28  Искандер Ф. - ...       ││  04:47 ━━━━━━━●──────────────────────── 1:27:40  │
│                                ││  |<  [ || ]  >|   *  [S]  (R)      (V) ━━━● 84%  │
├─ ЛОГ ─────────────────── [D] x ┤│  Поиск  Лог  Описание  Настройки   статус  [P][M]│
│ Найдено: 39 треков        (2)  │├─ ОПИСАНИЕ ПЕРЕДАЧИ ─────────────────────────── x ┤
│ > Воспроизведение: ...         ││  ID: 30791                                       │
│                                ││  Название передачи                         (3)   │
│                                ││  Текст описания, ссылки, картинки                │
└────────────────────────────────┘└──────────────────────────────────────────────────┘
```

| № | Элемент | Что это |
|---|---|---|
| **1** | Список | результаты поиска, программа передач или история |
| **2** | Лог | сообщения программы |
| **3** | Описание передачи | текст со страницы передачи, ссылки, картинки |
| **4** | Обложка | первая картинка со страницы передачи; клик — открыть страницу на сайте |
| **5** | Название трека | клик — показать описание играющей передачи |
| **6** | Статус | воспроизведение / пауза / загрузка / прямой эфир / остановлено |
| **A** | 📻 | программа передач staroeradio.ru |
| **B** | 🕐 | история и избранное |
| **D** | 🗑 | очистить лог |
| **S** | 💾 | скачать играющий трек |
| **R** | 📻 | прямой эфир |
| **V** | 🔊 | без звука / вернуть громкость |
| **P** | 📌 | окно поверх всех окон |
| **M** | ▭ | мини-плеер |

Кнопки плеера: ⏮ предыдущий, ⏸/▶ пауза, ⏭ следующий, ⭐ в избранное.
У каждой кнопки есть всплывающая подсказка — наведите и подождите полсекунды.

**Плеер — главная область окна.** Остальные панели можно скрыть
(см. [раздел 7](#7-панели-мини-плеер-строка-состояния)).
Если у плеера появляется свободное место, обложка становится крупнее.

## 2. Поиск, программа передач, история

### Поиск по базе

Введите слова в строку поиска и нажмите **Enter**.

- Ищутся записи, в которых есть **все слова запроса**, в любом порядке и в любом месте названия:
  по фамилии автора, названию, исполнителям, году записи.
- Регистр не важен. Ищется и часть слова: `лавр` найдёт «Лавренёв».
- Поиск идёт сразу по всем базам из папки `data/`. Записи staroeradio.ru выводятся первыми.
- Число найденных треков показывается в заголовке панели: «ПОИСК 39 треков».

Вставить запрос из буфера можно обычным **Ctrl+V** — в том числе в русской раскладке —
или через правый клик → «Вставить».

> 💡 Если играющий трек есть среди новых результатов, он сразу подсвечен,
> и ⏭ продолжит именно от него.

### 📻 Программа передач

Загружает расписание эфира staroeradio.ru:

```
── 3 октября ──
13:08  Раскин А. - Как папа отомстил немецкому языку - ...
13:14  Баринов М. - Цунами - (исп.: А.Кузнецов, ...)
── 4 октября ──
01:46  Крылов И. - Лжец. - Скупой и Курица ...
```

Записи из программы можно слушать, скачивать и добавлять в избранное, как обычные результаты поиска.
При самом первом запуске программы расписание загружается автоматически.

### 🕐 История и избранное

Показывает вверху **⭐ Избранное**, ниже — прослушанное по дням, свежие дни сверху.
Подробнее — в [разделе 8](#8-избранное-и-история).

## 3. Список: выбор и воспроизведение

| Действие | Результат |
|---|---|
| **Клик** по строке | трек **выбран** (подсвечен фоном), загружается его описание; воспроизведение не меняется |
| **Двойной клик** | воспроизвести трек |
| **Enter** | воспроизвести выбранный трек |
| Правый клик | меню: воспроизвести, скачать, сохранить в плейлист (см. [раздел 12](#12-контекстные-меню)) |

**Две подсветки в списке:**

- **фон** (по умолчанию синий) — выбранная строка;
- **цвет текста** (по умолчанию оранжевый) — играющий трек.

Так можно спокойно читать описания других передач, не прерывая прослушивание.

> Двойной клик по **уже играющему** треку не начинает его сначала.
> Если трек стоит на паузе, воспроизведение продолжится.

Строка под курсором мыши слегка подсвечивается. При переходе к следующему треку
список сам прокручивается к нему.

## 4. Плеер

### Кнопки

| Кнопка | Действие |
|---|---|
| ⏮ | **предыдущий прослушанный** трек — тот, что вы слушали до текущего, даже если его нет в текущем списке |
| ⏸ / ▶ | пауза / продолжить (**Пробел**) |
| ⏭ | следующий трек в текущем списке |
| ⭐ | добавить **играющий** трек в избранное |
| 💾 | скачать **играющий** трек в MP3 |
| 📻 | прямой эфир (см. [раздел 5](#5-прямой-эфир)) |

Когда трек заканчивается, автоматически начинается следующий в списке.
В конце списка воспроизведение останавливается.

### Перемотка

- **Клик в любую точку** полосы — переход к этому месту.
- Перетаскивание ручки — время слева меняется на ходу, переход происходит, когда отпустите кнопку мыши.
- **Колесо мыши** над полосой или **←/→** — перемотка на 10 секунд.

Время показывается как `04:47`, а для записей длиннее часа — как `1:27:40`.

### Громкость

- Клик или перетаскивание по ползунку.
- **Колесо мыши** над ползунком, значком 🔊 или процентами, а также **↑/↓** — громкость ±5 %.
- **Клик по 🔊** — выключить звук, повторный клик — вернуть прежнюю громкость.
  Значок меняется в зависимости от громкости: 🔇 🔈 🔉 🔊.

### Обложка

Показывается первая картинка со страницы передачи. Если картинок нет,
выводится заставка «Старое радио» (`data/Staroe_radio.png`).
**Клик по обложке** открывает страницу передачи в браузере.

### Запоминание позиции

При выходе запоминаются трек, позиция в нём, громкость и список результатов.
При следующем запуске воспроизведение продолжается с того же места.

### Заголовок окна

В заголовке окна, а значит и на панели задач, выводится название трека:
`▶ название` во время воспроизведения, `⏸ название` на паузе, `📡 название` в прямом эфире.

## 5. Прямой эфир

| Действие с кнопкой 📻 в плеере | Результат |
|---|---|
| **Клик** | включить текущий поток |
| **Двойной клик** | следующий поток по кругу: Музыка → Детское радио → Старое радио → … |
| **Правый клик** | меню выбора потока |

Потоки:

- 📻 **Старое радио** — основной эфир радиопостановок и передач;
- 🎵 **Музыка**;
- 🧒🏻 **Детское радио**.

Над названием показывается название потока, под ним — название передачи, которая сейчас в эфире.
Смена передачи записывается в лог.

### Обложка и описание в эфире «Старое радио»

Поток передаёт только название передачи, без ID. Поэтому программа ищет ID сама:

1. в **программе передач** staroeradio.ru — там ровно то, что идёт в эфире. Программа запоминается на 30 минут;
2. если там не нашлось — в локальной базе `data/staroeradio.txt`.

Сравнение идёт без учёта регистра, пробелов, знаков препинания и разницы «ё/е».
Если передача найдена, появляются её обложка и описание, а в логе — строка вида
«🔎 Эфир: ID 42807 (программа)». **Клик по названию** в плеере открывает описание этой передачи.

В эфире полоса перемотки не работает — это живой поток.

## 6. Описание передачи

Панель показывает:

- ID передачи;
- **название** — сразу видно, к какой передаче относится описание;
- аннотацию, исполнителей, год записи и другие сведения со страницы передачи;
- кликабельные ссылки (открываются в браузере);
- картинки со страницы, подогнанные по ширине панели.

**Когда загружается описание:**

- при клике по треку в списке;
- при начале воспроизведения;
- при **клике по названию трека в плеере** — так всегда можно вернуться к описанию играющей передачи;
- в эфире «Старое радио» — при смене передачи (см. [раздел 5](#5-прямой-эфир)).

Описания и картинки загружаются в фоне, интерфейс при этом не подвисает.
Недавние описания запоминаются и при повторном открытии появляются мгновенно.
Если быстро щёлкнуть по нескольким трекам подряд, показано будет описание последнего.

Для работы описаний нужен пакет `beautifulsoup4`.

## 7. Панели, мини-плеер, строка состояния

### Нижняя панель плеера

```
 Поиск   Лог   Описание   Настройки     последнее сообщение лога     ⬇ 3   [P] [M]
```

| Элемент | Действие |
|---|---|
| **◧ Поиск** | показать/скрыть панель поиска (**Ctrl+1**) |
| **≡ Лог** | показать/скрыть лог (**Ctrl+2**) |
| **▤ Описание** | показать/скрыть описание (**Ctrl+3**) |
| **⚙ Настройки** | окно настроек |
| сообщение | последнее сообщение лога; **клик** — открыть лог |
| ⬇ 3 | сколько файлов ждёт скачивания |
| 📌 | окно поверх всех окон |
| ▭ | мини-плеер (**Ctrl+M**) |

Включённые переключатели выделены акцентным цветом.
Панель можно скрыть и крестиком ✕ в её заголовке.

Расположение панелей:

- слева — **Поиск** и под ним **Лог**;
- справа — **Плеер** и под ним **Описание**.

Если скрыть и Поиск, и Лог, левая колонка исчезает и плеер занимает всю ширину окна.
Границы между панелями можно перетаскивать. Размеры и видимость панелей запоминаются.

### Мини-плеер

Кнопка ▭ или **Ctrl+M**: все панели скрываются, окно уменьшается до одного плеера.
Повторное нажатие возвращает прежний вид и размер окна.
Если в мини-режиме нажать любой переключатель панели, тоже вернётся полный вид.

Размер и положение мини-окна запоминаются. Если закрыть программу в мини-режиме,
она и откроется в нём.

> 💡 Мини-плеер удобно сочетать с 📌 «поверх всех окон».

## 8. Избранное и история

### ⭐ Избранное

- Кнопка ⭐ добавляет **играющий** трек, а не выделенную строку списка.
- Повторно тот же трек не добавляется — в логе будет «Уже в избранном».
- Хранится в `History/favorites.txt`.

### История

- Каждый прослушанный трек записывается в `History/дд.мм.гггг.txt`.
- Кнопка 🕐 выводит в список избранное, затем историю по дням.

### Предыдущий трек ⏮

Программа помнит порядок прослушивания в текущем сеансе.
⏮ возвращает к треку, который играл до текущего, даже если с тех пор вы делали другой поиск.

## 9. Скачивание и плейлисты

### Как скачать

| Способ | Что скачивается |
|---|---|
| 💾 в плеере | играющий трек |
| ПКМ по строке → **💿 Скачать: …** | этот трек |
| ПКМ → **💿 Скачать все треки** | все треки текущего списка |

Скачивание идёт в фоне по очереди. Число файлов в очереди видно в строке состояния (⬇),
ход скачивания пишется в лог. Слушать при этом можно как обычно.

### Куда сохраняется

Файлы сохраняются в подпапку **`Staroe_radio_downloads`** внутри папки,
заданной в **⚙ Настройки → Общие**:

```
<папка из настроек>/
└── Staroe_radio_downloads/
    ├── Лавренёв Б. - Простая вещь ....mp3         ← одиночные треки
    ├── Лавренёв Б. - Простая вещь ....m3u
    └── лавренёв/                                    ← «скачать все» / «сохранить все»:
        ├── ...mp3                                      подпапка по поисковому запросу
        └── лавренёв.m3u
```

Если в настройках включено **«Спрашивать папку при каждом сохранении»**,
папка выбирается в диалоге при каждом скачивании.

### ID3-теги

В скачанные MP3 записываются:

- **название** — полное название записи;
- **год записи** — берётся из названия, например «(Зап.: 1987г.)»; для «1940-х гг.» записывается 1940;
- **комментарий** — описание передачи со страницы;
- **обложка** — первая картинка со страницы.

Для тегов нужен пакет `mutagen`. Без него файлы скачиваются без тегов.

### Плейлисты M3U

- ПКМ → **💾 Сохранить: …** — плейлист из одного трека.
- ПКМ → **💾 Сохранить все в плейлист** — все треки списка.

В плейлисте хранятся **ссылки** на потоки, а не сами файлы. Такой плейлист открывается
в VLC, AIMP и других плеерах, которые умеют проигрывать по сети.

## 10. Настройки

Кнопка **⚙ Настройки** на нижней панели плеера. Пока окно открыто, кнопка подсвечена.

```
┌──────────────┬──────────────────────────────────────────────────┐
│ НАСТРОЙКИ    │  Плеер                                           │
│              │                                                  │
│  Общие       │  НАЗВАНИЕ ТРЕКА                                  │
│ >Плеер       │  ┌────────────────────────────────────────────┐  │
│  Кнопки      │  │ Цвет текста        [###] #D5B491   ↺       │  │
│  Поиск       │  │ Размер шрифта            −  13  +          │  │
│  Описание    │  │ Начертание   Обычный Жирный Курсив Ж+К     │  │
│  Лог         │  └────────────────────────────────────────────┘  │
│  Схемы       │                                                  │
├──────────────┴──────────────────────────────────────────────────┤
│ Изменения видны сразу    ↺ Отменить изменения  Сохранить Закрыть│
└─────────────────────────────────────────────────────────────────┘
```

### Разделы

| Раздел | Что настраивается |
|---|---|
| **Общие** | папка сохранения, «спрашивать каждый раз», цвет заголовка окна Windows, цвет разделителей между панелями, цвет заголовков панелей |
| **Плеер** | название трека (цвет, фон, размер, начертание), фон плеера, цвет времени и статуса, цвет громкости, **цвета ползунков** |
| **Кнопки** | цвет значков, подсветка при наведении, **акцентный цвет** (кнопка ▶ и включённые переключатели) |
| **Поиск** | номер, название, **играющий трек**, заголовок даты, время передачи, выделенная строка, фон |
| **Описание** | текст, заголовок, ссылки, размер и начертание шрифта, фон |
| **Лог** | цвета сообщений об успехе, ошибке, предупреждении и обычных, фон |
| **Схемы** | сохранение и загрузка наборов цветов |

### Как менять цвета

Каждый цвет — это образец, поле HEX и кнопка ↺.

- **Клик по образцу** открывает палитру:
  - готовые цвета — серые и 8 оттенков по 5 уровней яркости;
  - **недавние** — цвета, выбранные в этом сеансе;
  - **◐− / ◑+** — немного темнее / светлее;
  - поле HEX, **Enter** — применить и закрыть;
  - **Системная палитра…** — стандартный диалог Windows;
  - **Готово** или **Esc** — закрыть. Палитра закрывается и при клике мимо неё.
- **Поле HEX** — можно ввести код вручную (`#3d7be0`). Неверный код подсвечивается красной рамкой.
- **↺** — вернуть значение по умолчанию. Само значение видно в подсказке.

### Применение и сохранение

- Изменения **сразу видны** в главном окне. Внизу появляется «● Есть несохранённые изменения».
- **Сохранить** — записать в `colors_config.json`.
- **↺ Отменить изменения** — вернуть то, что сохранено в файле.
- **Закрыть** с несохранёнными изменениями — внизу появится вопрос
  «Сохранить / Не сохранять / Отмена».

Папка сохранения и «Спрашивать каждый раз» применяются сразу и запоминаются вместе с состоянием программы.

### Цветовые схемы

Раздел **Схемы**:

- **Применить** или двойной клик — загрузить выбранную схему. Её цвета сразу видны,
  останется только нажать «Сохранить»;
- поле внизу и **«Сохранить текущие цвета как схему»** — сохранить под именем;
- **Удалить** — нажмите дважды: первый раз кнопка спросит «Точно удалить?».

Схемы хранятся в папке `color_schemes/`, по одному `.json` на схему.

## 11. Горячие клавиши и мышь

### Клавиатура

| Клавиши | Действие |
|---|---|
| `Пробел` | пауза / продолжить |
| `←` / `→` | перемотка на 10 секунд назад / вперёд |
| `↑` / `↓` | громкость +5 % / −5 % |
| `Ctrl+F` | перейти в строку поиска (панель откроется, если скрыта) |
| `Ctrl+1` | показать/скрыть **Поиск** |
| `Ctrl+2` | показать/скрыть **Лог** |
| `Ctrl+3` | показать/скрыть **Описание** |
| `Ctrl+M` | мини-плеер |
| `Enter` в строке поиска | искать |
| `Enter` в списке | воспроизвести выбранный трек |
| `Ctrl+C` | копировать выделенный текст (список, описание, лог) |
| `Ctrl+V` | вставить в строку поиска |

Все сочетания с Ctrl работают **в любой раскладке**.
Пробел и стрелки не срабатывают, пока курсор стоит в строке поиска, — там они нужны для набора текста.

| Где | Действие |

| обложка | клик — страница передачи на сайте |
| полоса перемотки | клик — переход, колесо — ±10 секунд |
| ползунок громкости, 🔊, % | колесо — громкость ±5 % |
| 🔊 | клик — без звука / вернуть |

| граница между панелями | перетаскивание — размер панелей |

## 13. Файлы программы

| Файл / папка | Назначение |
|---|---|
| `data/*.txt` | локальные базы записей (`ID<TAB>Название`) |
| `data/Staroe_radio.png` | заставка, когда у передачи нет обложки |
| `icon.ico` / `icon.png` | значок окна (необязательно) |
| `player_state.json` | трек и позиция, громкость, результаты поиска, окно, панели и их размеры, мини-режим, «поверх окон», папка сохранения |
| `colors_config.json` | цвета и шрифты |
| `color_schemes/` | именованные цветовые схемы |
| `History/дд.мм.гггг.txt` | история прослушивания по дням |
| `History/favorites.txt` | избранное |
| `libvlc.dll`, `libvlccore.dll`, `plugins/` | VLC, если он не установлен в систему |

Чтобы сбросить все настройки внешнего вида, удалите `colors_config.json`.
Чтобы сбросить окно и панели, удалите `player_state.json`: при следующем запуске
загрузится программа передач, как при первом запуске.

## 14. Вопросы и решения

**Нет звука, в логе ошибка VLC.**
Установите VLC той же разрядности, что и Python (обычно 64-бит), или положите рядом
со скриптом `libvlc.dll`, `libvlccore.dll` и папку `plugins`.

**Описание не загружается, в описании просьба установить beautifulsoup4.**
`pip install beautifulsoup4`

**Скачанные MP3 без названия и обложки.**
`pip install mutagen`

**Поиск ничего не находит / «Нет TXT файлов».**
Базы должны лежать в папке `data/` рядом с программой.

**Значок окна не меняется.**
Файл должен называться `icon.ico` или `icon.png` и лежать рядом с программой.
В логе при запуске видно, какой значок взят: «🖼 Значок окна: …».

**В эфире «Старое радио» нет описания.**
Передача не нашлась ни в программе передач, ни в `data/staroeradio.txt` — в логе будет об этом сообщение.
Обычно помогает обновить базу. Для потоков «Музыка» и «Детское радио» описания нет.

**Цвет заголовка окна не меняется.**
Работает в Windows 10 (сборка 19041 и новее) и Windows 11.

**Окно открылось слишком маленьким или за краем экрана.**
Удалите `player_state.json`.
